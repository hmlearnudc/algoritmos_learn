# Algoritmos

Repositorio de apoyo para la asignatura **Algoritmos**.

Aquí encontrarás ejemplos, ejercicios y otros recursos utilizados durante el desarrollo de las clases.

## Temas

Inicialmente trabajaremos los siguientes contenidos:

- Estructuras condicionales
- Ejercicios resueltos
- Ejercicios propuestos

## Lenguaje

Los ejemplos serán desarrollados principalmente en **Python**.

## Uso del repositorio

Los estudiantes pueden consultar directamente los archivos desde GitHub o descargar el repositorio para trabajar en sus computadores.

Para clonar el repositorio:

git clone https://github.com/hmlearnudc/algoritmos_learn.git
